# 管理员后台说明

> 形态：**小程序内的管理页**，不是独立 Web 后台。
> 理由：直接复用现有 `openid` 鉴权、云函数与数据权限；独立后台要另建工程、另做登录、还要绕云开发 HTTP 访问，成本远高于收益。

---

## 一、入口与跳转关系

```
「我的」页
   └─ 管理员后台（仅 isAdmin 可见，橙色高亮）
        └─ 数据概览 dashboard
              ├─ 用户管理 users
              ├─ 举报处理 reports
              ├─ 内容治理 content
              ├─ 角色权限 roles
              ├─ 操作日志 logs
              ├─ 系统设置 settings
              └─ 快捷入口卡片（同上五项）
```

- 六个页面顶部共用 `admin-nav` 组件，横向 Tab 直接互跳（`wx.redirectTo`，页面栈不膨胀）
- 左上角「‹ 返回」退回「我的」；页面栈为空时降级为 `switchTab`
- 概览页的「快捷入口」卡片是第二跳转路径，和管理端 Tab 等价
- 角色页底部的「去用户管理授予角色」跳到 users

## 二、权限模型

| 等级 | 来源 | 能力 |
|---|---|---|
| **root** | 云函数环境变量 `ADMIN_OPENIDS`（逗号分隔 openid） | 全部能力，含删除用户、调整角色。**不能在后台被降级或删除** |
| **admin** | `users.role = 'admin'` | 查看概览、管理用户（增删改查、禁用/启用）、清理内容、查日志、改设置。**不能删用户、不能改角色** |
| 普通用户 | 默认 | 看不到入口 |

三道服务端判定，前端只是隐藏入口，不具备安全性：

1. `login` 返回 `isAdmin`，前端据此显示菜单
2. 每个 `admin.*` action 首行 `assertAdmin(ctx)`，不通过返回 `FORBIDDEN`
3. 高危操作（删用户、改角色）额外校验 `level === 'root'`

**防呆规则**（服务端强制）：

- 不能禁用 / 删除自己
- 不能操作 root 账号
- 批量操作单次上限 50 条

## 三、六个模块

### 1. 数据概览 `pages/admin/dashboard`

- 四张指标卡：用户总数（含今日新增）、任务总数（含待接）、进行中（含已完成）、待处理举报（含话题/评论总量）
- 近 7 天新增趋势：**纯 WXSS 柱状图**，橙色=任务、蓝色=新用户，不引第三方图表库（省体积、避免 canvas 适配问题）
- 快捷入口卡片
- 下拉刷新

### 2. 用户管理 `pages/admin/users`

- 搜索：按昵称模糊匹配
- 筛选：全部 / 正常 / 已禁用
- 分页：触底加载，`limit+1` 判断 `hasMore`
- 新增：昵称 + openid + 信用分 + 角色（root 可见）
- 编辑：昵称 / 信用分 / 角色
- 单条：启用 / 禁用、删除（root）
- 批量：勾选后底部操作条，支持批量启用 / 禁用 / 删除
- 校验：昵称 2–20 字、openid 必填且不重复、信用分 0–1000，错误红字挂在字段下方

### 3. 举报处理 `pages/admin/reports`

闭环流程：**接收 → 查看 → 处置 → 结案**。

- Tab 筛选：待处理 / 已处理 / 已忽略 / 已删除 / 全部
- 列表展示：目标类型标签、内容快照、举报理由、补充说明、举报人与时间
- 「查看内容」：任务/话题跳对应详情页；评论无详情页，弹快照
- 三种处置：

| 动作 | 效果 | 状态 |
|---|---|---|
| 标记已处理 | 仅结案，不动内容 | `resolved` |
| 忽略 | 判定为误报 | `ignored` |
| 删除内容 | 物理删除目标（任务/话题连带删评论） | `removed` |

点任一处置按钮会打开**处置弹层**：动作可改选、可填处置备注（≤200 字），一次提交。删除动作会在提交前再弹一次不可恢复确认。

备注写入 `reports.handleNote`，同时进操作日志，已处理的举报在列表里直接展示「处置备注」，事后能查为什么这么判。

**关键设计**：处理一条举报时，**同一内容下的其它待处理举报一并结案**，避免对同一条违规内容反复点三次。

概览页「待处理举报」指标卡可直接点进本页。

### 4. 内容治理 `pages/admin/content`

- 三个类型 Tab：任务 / 话题 / 评论
- 搜索：标题或正文关键词
- 单条删除、批量删除
- 删除任务或话题时，**级联清理其下评论**（服务端处理）

### 5. 角色权限 `pages/admin/roles`

- ROOT 列表：来自环境变量，只读，标注「后台不可增删改」
- 管理员列表：可撤销（root）；授予走「用户管理 → 编辑 → 角色」
- 非 root 进入只读，按钮隐藏

### 6. 操作日志 `pages/admin/logs`

记录所有写操作，字段：

| 字段 | 说明 |
|---|---|
| `operatorOpenid` / `operatorLevel` | 操作人与等级 |
| `action` | `user.create` / `user.update` / `user.setStatus` / `user.delete` / `content.remove` / `role.update` / `settings.save` / `report.resolve` / `report.ignore` / `report.remove` |
| `targetType` / `targetId` | 目标对象 |
| `detail` | JSON 摘要，截断 500 字符 |
| `createdAt` | 服务端时间 |

- 按操作人 openid 搜索、触底分页
- 写日志失败不阻断主流程（`console.warn` 后继续）

### 7. 系统设置 `pages/admin/settings`

存 `settings` 集合（`key='global'` 单文档）：

| 项 | 校验 |
|---|---|
| 单任务赏金上限 | 0–100000 |
| 自动下架举报阈值 | 1–100 |
| 大厅公告 | ≤ 200 字 |
| 允许发布新任务 | 开关 |

前端校验 + 服务端二次校验（服务端为准）。「举报阈值」目前只落库，自动下架逻辑未接（等 P1-7 定时任务）。

## 四、交互与视觉一致性

所有后台页面共用 `styles/admin.wxss`（每页 `@import`），统一：

| 元素 | 规范 |
|---|---|
| 页面底色 | `#f2f4f7`，卡片白底圆角 20rpx |
| 导航 | 顶部返回 + 标题，下方胶囊 Tab，选中态黑底白字 |
| 筛选条 | 圆角搜索框 + 右侧胶囊按钮，一行放得下 |
| 列表行 | 白底 16rpx 圆角；标题单行省略，meta 灰色 22rpx |
| 批量条 | 固定底部黑底浮条，左侧计数，右侧操作，可取消 |
| 表单 | 底部弹层，字段纵向排列，错误红字在字段下方 |
| 空态 / 加载 | 居中灰字，加载中与「加载更多」分开 |

**响应式**：全用 `rpx`，指标卡按 2 列 50% 宽自适应，窄屏（iPhone SE）单卡最小 320rpx 不挤压；批量条左右留 24rpx 安全边距；所有弹层底部加 `env(safe-area-inset-bottom)` 适配全面屏。

## 五、真实限制

1. **不是 PC 后台**。要 PC 端需要独立 Web 工程 + 云开发 HTTP 访问 + 另一套登录鉴权，工作量和风险都大得多。当前形态在手机上完成日常治理够用。
2. ~~举报处理没有闭环~~ ✅ 已补：新增「举报处理」页，支持标记已处理 / 忽略 / 删除内容，同目标自动合并结案。
3. ~~设置项只有存储，没有消费方~~ ✅ 已接入：`task.create` 读取 `settings`，超赏金上限或发布开关关闭会直接拒绝；发布页显示上限提示，开关关闭时禁用入口；大厅顶部展示公告。
4. **用户「新增」是预置档案**，主要用于内部账号或数据迁移，正常用户仍由微信登录自动建档。

## 六、验收清单

| # | 操作 | 预期 |
|---|---|---|
| A1 | 用非管理员账号进「我的」 | 看不到管理员后台入口 |
| A2 | 直接访问 `/pages/admin/dashboard/index` | 弹「无权访问」并退回 |
| A3 | root 身份进入概览 | 显示四张卡 + 7 天柱状图，数据非空 |
| A4 | 用户列表搜昵称 | 结果过滤，空结果有提示 |
| A5 | 用户列表勾选 2 个 → 批量禁用 | Toast 提示数量，列表刷新为已禁用 |
| A6 | 新增用户，昵称填 1 个字 | 字段下方红字「昵称需 2-20 个字」，不提交 |
| A7 | 编辑自己 → 禁用 | 服务端拒绝「不能操作自己的账号」 |
| A8 | 普通管理员进角色页 | 撤销按钮不可见 |
| A9 | 内容治理删一条任务 | 列表刷新，任务下评论被级联清理 |
| A10 | 保存设置，赏金上限填 -1 | 红字提示，不提交 |
| A11 | 任意写操作后查日志 | 能看到对应 action 记录 |
